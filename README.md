# AVERTIQ

**AI-Assisted Disaster Impact Analysis and Adaptive Rescue Optimisation**

Tagline: Anticipate Risk. Optimise Rescue.

## Technology Stack

- Frontend: HTML5, CSS3, Vanilla JavaScript
- Backend: Node.js and Express.js
- Database: MongoDB with Mongoose
- Maps: Leaflet.js
- Charts: Chart.js
- Routing: Dijkstra shortest-path algorithm
- Decision support: Priority scoring and resource allocation

## Project Status

Initial project structure created. Features will be implemented incrementally using simulated disaster scenarios.

## Safety and Data

This project is a decision-support prototype. Simulated data and illustrative priority scores must not be treated as verified emergency predictions or operational rescue instructions.

Backend setup and frontend implementation instructions will be added as development progresses.
